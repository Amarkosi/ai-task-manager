# 🚀 Инструкция по проверке и запуску AI Канбан-менеджера задач

Вы можете запустить и проверить проект любым удобным для вас способом:

---

## 🔹 Способ 1. Автоматический деплой в один клик (Рекомендуемый)

Благодаря настроенной облачной конфигурации `render.yaml` (Blueprint), вы можете мгновенно развернуть личную, 100% активную копию всей экосистемы (Бэкенд, Бот, Воркер, Доска) в своём аккаунте хостинга всего в один клик:

👉 **https://render.com**

При переходе по ссылке Render автоматически развернет структуру и выведет на экран безопасные пустые поля. Вам потребуется лишь вставить туда ваши личные токены:
* `BOT_TOKEN` — токен вашего Telegram-бота от @BotFather.
* `GROQ_API_KEY` — API-ключ от платформы Groq (Whisper).
* `DATABASE_URL` — ссылка СУБД (например, Neon PostgreSQL).
* `REDIS_URL` — ссылка на облачный защищенный Redis (например, Upstash).

---

## 🔹 Способ 2. Локальный запуск через Docker-Compose (Рекомендуемый, если нет готовых облачных ключей)

Если у вас нет зарегистрированных аккаунтов в Neon PostgreSQL, Upstash Redis или Groq Cloud, этот способ — самый быстрый. 

Вам не нужно ничего регистрировать: контейнеры локальной базы данных PostgreSQL и брокера очередей Redis развернутся автоматически внутри Docker. Вам понадобится вставить только токен любого тестового Telegram-бота.

1. **Клонируйте репозиторий с исходным кодом:**
   ```bash
   git clone https://github.com
   ```
2. **Зайдите в корневую папку проекта:**
   ```bash
   cd ai-task-manager
   ```
3. **Укажите токен бота:**
   Откройте файл `docker-compose.yml` текстовым редактором, найдите секцию `bot` и вставьте токен вашего тестового бота в переменную `BOT_TOKEN`.
4. **Вставьте ИИ-ключ (опционально):**
   Если хотите протестировать ИИ-расшифровку голоса, вставьте ваш ключ Groq в переменную `GROQ_API_KEY` в секции `worker`. Если ключа нет, текстовые задачи через бота и Канбан-доска всё равно будут работать в полном объёме.
5. **Запустите всю систему одной командой:**
   ```bash
   docker-compose up -d --build
   ```

### 📋 Ссылки для локальной проверки:
* **Интерактивная Канбан-доска (React):** `http://localhost:8080/?user_id=ВАШ_TELEGRAM_ID`
* **Бэкенд API (FastAPI Swagger):** `http://localhost:8000/docs`

## 🎯 Что протестировать в проекте:
1. **Текстовый ввод:** Отправьте боту текстовое сообщение (например, *«Купить продукты»*). Бот моментально пришлет персональную ссылку, а карточка сразу появится на доске.
2. **ИИ-расшифровка голоса:** Запишите боту голосовое сообщение на русском языке. В фоновом режиме Celery-воркер переведет аудио в Base64, Whisper распознает речь, а бэкенд пушит задачу на экран.
3. **Real-time WebSockets:** Нажимайте на кнопки изменения статуса карточек (*«📥 В ожидание»*, *«⚡ В процесс»*, *«✅ Завершить»*). Карточки плавно перелетают между колонками в реальном времени без перезагрузки страницы.
4. **Удаление заметок:** Нажмите на красную кнопку *«🗑️ Удалить»*, чтобы полностью стереть задачу из базы данных.
